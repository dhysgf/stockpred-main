这一页能做什么、不能做什么

能：实时看任意沪深/科创板个股的现价、涨跌、开高低、量额、量比、换手，以及当日分时走势。 数据来自东方财富 push2 / push2his 公开接口（带 CORS，浏览器可直连）。
不能：这里没有预测。14 路专家要按历史误差在线调权、逐 tick 结算， 那是常驻进程干的活，静态站点算不了——预测请看预测看板里的真实运行快照。
盘中每 3 秒刷新一次；收盘后价格定格，页面不再变化。行情有延迟，仅供研究，不构成投资建议。
数据源：东方财富公开行情接口（浏览器直连，跨域头为 *）。
本页不经过任何自建服务器，也不记录你的查询。本项目仅用于技术研究与系统设计演示。
