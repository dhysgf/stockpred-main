怎么让这个看板真的动起来

实时服务必须跑在**自己的机器**上（本机 / VPS / 内网穿透），Pages 托管不了常驻进程。 
python live.py --port 8020          # 启动实时服务
python live.py --rank               # 顺便起涨幅榜
python run.py --sync-db 600519      # 同步日线与指标入库
然后打开 http://127.0.0.1:8020/live?code=600519： 每 3 秒刷新行情与 14 路预测，收盘后自动切换回放模式继续跑。
