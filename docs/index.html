哪些能实时，哪些只能是快照

内容实时性原因
股价与分时真·实时 行情接口带 CORS（Access-Control-Allow-Origin: *），浏览器可直连， 实时报价每 3 秒刷新一次，服务器不参与
14 路预测只能是快照 要按已实现误差在线调权、逐 tick 结算，属于常驻进程；GitHub Pages 只有静态文件， 没有执行环境，算不了 Hedge 权重，也写不了库
所以预测看板上的每个数字都是真实运行的固化结果——来自本机引擎实测， 不是示意值，但不会自己刷新。能刷新的只有行情本身。
想让预测也每 3 秒跳动，必须跑在常驻进程上（本机 / VPS / 内网穿透）：
python live.py --port 8020        # 实时服务（含 /live 与 /rank）
python live.py --rank             # 同时挂载涨幅榜
python run.py --sync-db 600519    # 同步日线与指标入库
然后访问 http://127.0.0.1:8020/live?code=600519。

站点范围 只讲实时系统

本站只展示实时分钟级预测这一套：14 路专家、Hedge 在线加权、到期结算、涨幅榜爬虫。 日线多模型报告已从站点下线，相关代码仍在仓库里（run.py / make_report.py）， 本地跑 python web.py 即可生成。
数据源：新浪 / 腾讯行情、东方财富榜单（均为免 token 公开接口）。
页面由 tools/build_live_snapshot.py、tools/build_rank_snapshot.py 从 data/stockpred.db 直接生成，未经手工修改。
本项目仅用于技术研究与系统设计演示，所有输出不构成投资建议。
